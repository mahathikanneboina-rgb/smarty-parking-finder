How to Run:

  1. Make sure Node.js server is running (`npm start`).
  2. Install python requirements: `pip install opencv-python ultralytics requests`.
  3. Run the Python script: `python ai_detector.py`.
  4. Watch the camera feed detect cars and instantly update the Web Parking Map!
